# ESP32-S3 Camera v1.4 — 3D 列印外殼（SolidWorks 2024）

相機式兩片殼：**前殼**（鏡頭與凸起鏡座環、上牆的快門帽、BOOT/RESET 針孔、三個 LED 導光孔、左側握持溝紋、USB-C 與電源開關的開口）＋**後殼**（內縮邊框的螢幕窗、記憶卡插槽、四支板子立柱、四支螢幕定位柱），外緣整圈 R2.5 倒圓、直角 R4.5，用四支 M2×25 螺絲從背面鎖穿。整組 **65 × 90 × 27.6 mm**（鏡座環再凸 1.5），壁厚 2 mm。
所有零件都是 `build_enclosure_sw.py` 透過 SolidWorks COM API 依 v1.4 板檔的座標畫出來的，改尺寸就改腳本開頭的參數重跑。v1.3 版外殼（三顆正面按鈕帽）已被取代。

## 座標系

組合件用板子座標：X = KiCad x，Y = −KiCad y，Z = 0 在板子**頂面**（鏡頭那一面），板底 Z = −1.6。
前殼佔 Z 0 ～ +9，後殼佔 Z −18.6 ～ 0，分模線就在板子頂面。KiCad 的 STEP 是 Y 上下顛倒的右手座標，所以直接對得上，只平移 Z。

## 列印與組裝

- **前殼**：外面朝下平放列印（開口朝上），上牆的快門窗是側面開口，2 mm 跨距不需支撐。**後殼**：底板朝下，立柱直接往上長，不需支撐；螢幕窗上緣若有垂料可加橋接設定。**快門帽**：凸緣朝下、頭朝上。
- 材料 PLA/PETG 皆可；預估 PLA 用量前殼約 20 g、後殼約 29 g。層高 0.2 mm、壁 3 圈。
- 螺絲：**M2 × 25 mm 盤頭** ×4，從後殼底部沉孔穿過立柱與板子，自攻進前殼的 Ø1.6 導孔。先用 M2 螺絲在前殼導孔上預攻一次再組。
- 組裝順序：① 螢幕窗框內側貼 0.5 mm 泡棉膠 ② 螢幕模組插上 J5、亮面朝外 ③ 板子連螢幕放進後殼，先讓四支定位柱對進螢幕四角的孔，再讓板子四角落在立柱上 ④ 快門帽從前殼內側塞進上牆的窗，凸緣留在牆內 ⑤ 前殼蓋上，唇口對進凹槽 ⑥ 翻面鎖四支螺絲。相機模組與電池用泡棉膠照 `../README.md` 貼好再蓋。
- 板子與殼壁間隙 0.5 mm，FDM 列印若內縫收縮，用刀修一下唇口即可。

## 第一次實體驗證要看的

1. 相機模組含鏡頭實際高度：內高 7 mm 是估的，鏡頭筒要能穿出 Ø10 孔且模組不被壓到；不合就改 `FRONT_CAV`。
2. 螢幕模組插上後玻璃面離板底的實測值（設計值 13.9 mm）與四角孔是否對到定位柱；柱子頂到模組背面才算對，差太多就改 `DISPLAY_MODULE["back_zb"]`。
3. 電源開關撥桿能否從指窪撥動；不行就把 `SW4["pocket_depth"]` 加到 1.5。
4. 快門手感：預行程 0.26 mm 太多就把 `SHUTTER["flange_t"]` 加到 1.0；快門帽在窗裡卡住就把 `head_w`/`head_h` 各減 0.2。
5. 針孔按 BOOT/RESET 順不順手：不順就把 `PINHOLE_D` 放大到 2.5。

## 這版刻意沒做

LED 分兩面、開口分三邊（右邊 USB-C 與開關、左邊記憶卡、上邊快門），這些是板子 v1.4 定案時決定不改的；外殼跟著板子。沒有腕帶孔、腳架螺孔與品牌文字，要加請在 SolidWorks 裡直接改零件，或在腳本加特徵後重跑（腳本會覆寫同名檔案）。
