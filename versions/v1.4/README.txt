v1.4 — 2026-09-22 定稿（v1.3 未下單，直接改成 v1.4）。
起因：三顆按鍵都在鏡頭面左欄，拿相機時要繞到前面盲按，不符合人體工學。
相對 v1.3 的改動：快門 SW3 從頂面按壓式 SKQG (9, 40) 換成側按式 ALPS SKRTLAE010（LCSC C110293），
放在上板邊右段 (50.6, 2.6) 轉 180 度，觸桿朝板邊伸出，桿頭在 y = 0.56，由外殼上牆的快門帽按壓。
封裝用專案內複本 esp32s3-camera:SW_Push_SKRTLAE010_Side（焊盤 1 由 0.75 縮到 0.55 mm，與定位孔留 0.15 mm）。
C12 下移 0.8 mm 到 (47.5, 6.3) 讓位；刪掉 GND 縫合過孔 (51,3)、(54,3)、(22.4,73.8)、(40,73.8)；IPROG 頂層斜線改繞 GND 過孔 (45.7,7.3)。
BTN_SHUTTER 走線：U1 pin 39 (21.25,72.49) 往左打過孔 (19.4,73.4)，底層沿模組下方 y = 73.3..73.4 到右板邊，沿 x = 59.35 往上到 y = 2，過孔 (53.8,2) 回頂層接 SW3；
原本到左欄 SW3 的 16 段頂層走線刪除。SW1 BOOT、SW2 RESET 不動。
58 顆 SMD 不變（SW3 換料號），CPL 只有 C12 與 SW3 兩行不同；插件 J4、J5。零件 60 顆。絲印、標題欄、Gerber ProjectId 皆為 v1.4。
驗證：ERC 0 錯誤（2 個 XC6206 符號庫警告）；DRC 含原理圖一致性 0 錯誤、0 警告、0 未連接、0 一致性問題；gnd_connectivity.py GND / +3V3 全部焊盤在主群集。
內容：原理圖、板檔、專案檔、網表、ERC/DRC 報告、fab/（Gerber zip、鑽孔、BOM 34 行、CPL 58 顆、JLCPCB-上傳-v1.4、下單清單、採購清單）、自訂 footprint 庫。
外殼：enclosure/ 同步改為 v1.4（快門帽在上牆、BOOT/RESET 針孔），組合件干涉 0 件。
