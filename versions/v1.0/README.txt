ESP32-S3 Camera — v1.0 存檔（2026-09-17 改 J2 腳位前的最後狀態）
==================================================================

這三個檔案原本是根目錄的 *.bak_before_j2fix，2026-09-18 整理時改回正常檔名搬到這裡。

與 v1.1（根目錄正式檔）的差異：
- J2 相機 FPC 座腳位是舊定義，對不上 AI-Thinker ESP32-CAM 標準 24pin，和 v1.1 的韌體 camera_config_t 不相容。
- 沒有相機 LDO U5（2.8V）、U6（1.2V）和 C12–C17，共 53 個零件。
- 設計規則較鬆：間距 0.127 mm、線寬 0.15 mm；沒有 Plane 網路類別。
- 絲印文字為「rev A」，無標題欄版本號。

用途只有回頭對照，不要拿這一版出 Gerber 或下單。
專案內建封裝 ESP32-S3-WROOM-1-Cam 已內嵌在 .kicad_pcb 裡，直接開 .kicad_pro 即可，不需要 fp-lib-table。
